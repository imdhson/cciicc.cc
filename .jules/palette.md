
## 2024-12-10 - Empty States for Space Joining
**Learning:** Guests or hosts joining a newly created room experience a blank white page if no file is uploaded. This causes confusion as users don't know if the application is loading or waiting for action.
**Action:** Always add an empty state with helpful guidance (e.g., instructions for the host or a wait message for the guest) and dynamically hide it when content (PDF/media) loads.
